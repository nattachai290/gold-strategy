## Rules

- Do not edit anything under `goldml/`, `tests/`, `experiments/`,

- If any step fails, stop, write what happened (command, full error) to

## Steps

1. Make sure you are on an up-to-date `main` that contains
   `experiments/e001_first_models.py` and `prompts/R001.md`.
2. Install: `pip install -e '.[dev]'`
3. Tests must pass before the run: `pytest` (expect 22 passed). If not, stop (rule above).
4. Restore the XAU data (not in git): `python -m goldml.dukascopy restore`
   must print `restore OK`. A hash mismatch is a failure (rule above).
   Then `git status --porcelain data/` must print nothing.
5. Run:
   ```bash
   python -m goldml.run experiments/e001_first_models.py --run-id R001
   ```
   Expect a few minutes. It prints a markdown table.
6. Confirm these exist: `results/R001/summary.md`, `results/R001/<experiment>/metrics.json`
   and `oos.csv` for all 4 experiments, 4 new rows in `results/trials.csv`,
   and an updated `results/LEADERBOARD.md`.
7. Write `results/R001/RUNNER_NOTES.md` with: date/time, `git rev-parse HEAD`,
   Python and package versions (`pip list | grep -iE "numpy|pandas|scikit|lightgbm"`),
   wall-clock duration, and any warnings printed. Facts only, no interpretation.
8. Commit:
   ```bash
   git add results/
   git commit -m "R001: first models (4 trials) results"
   git push origin main
   ```
